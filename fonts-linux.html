<h1 id="font-settings-in-linux-distros-suck--write-your-own-fontconf">Font Settings in Linux Distros Suck – Write Your Own <em>font.conf</em></h1> <ul> <li>You can write your own font configuration file — <code>fonts.conf</code> — and change default settings.</li> <li>You can also use it to specify what fonts will be rendered on websites (as replacements for names specified in a site's CSS).</li> <li>Store <code>fonts.conf</code> at <code>$XDG_CONFIG_HOME/fontconfig/</code>, which probably means <code>$HOME/.config/fontconfig/</code>.</li> <li>Common places for storing fonts in Linux systems are <code>$HOME/.local/share/fonts</code> and <code>/usr/local/share/fonts</code>.</li> </ul> <h2 id="fonts-on-linux-and-the-web">Fonts on Linux and the Web</h2> <p>When you're visiting a website with <em>font-face</em> configured as <em>serif</em> or <em>sans-serif</em>, or more specifically, <em>Helvetica, Arial</em>, you can see one of the Linux world's not-so-good sides. Your visual experience is likely worst than those who actually can see <em>Helvetica</em> or even <em>Arial</em>. You probably got something like <em>Liberation Sans</em>, <em>DejaVu Sans</em>, or <em>Ubuntu</em>, which often don't look good on a page made with something else in mind.</p> <p>To give you a better example, I picked some common settings from the Web:</p> <ul> <li><code>Arial, sans-serif</code> — used at google.com.</li> <li><code>-apple-system, BlinkMacSystemFont, &quot;Segoe UI&quot;, Helvetica, Arial, sans-serif</code> — at GitHub.</li> <li><code>-apple-system, BlinkMacSystemFont, &quot;Segoe UI&quot;, &quot;Liberation Sans&quot;, sans-serif</code> — at StackOverflow.</li> </ul> <p>Pretty safe bets, but I don't think <em>GitHub</em> or <em>StackOverflow</em> fonts are all same quality and look. A typical Linux system will most likely select its default <em>sans-serif</em> in those cases. It will work OK, but might not be what you want aesthetically.</p> <p>But it is Linux, so you can change that.</p> <h2 id="picking-a-typeface">Picking a Typeface</h2> <p>There are <strong>good, free, and open-source</strong> typefaces that blend better in the web context than many default choices.</p> <p>It's good to pick the ones that look clean and familiar. The main goals for your default serif and sans-serif are legibility and predictable behavior, then style.</p> <p>Test them in a real context — a navigation bar is a different beast than body text.</p> <p>Put your downloaded fonts into one of those places:</p> <ul> <li><code>$HOME/.local/share/fonts</code></li> <li><code>/usr/local/share/fonts</code></li> </ul> <p>Here are my favorites:</p> <p>Sans-serif:</p> <ul> <li><a href="https://fonts.google.com/specimen/Roboto">Roboto</a> (used often at Google's sites)</li> <li><a href="https://rsms.me/inter/">Inter</a></li> <li><a href="https://github.com/IBM/plex">IBM Plex Sans</a></li> </ul> <p>Serif:</p> <ul> <li><a href="https://fonts.google.com/specimen/Merriweather">Merriweather</a></li> <li><a href="https://github.com/IBM/plex">IBM Plex Serif</a></li> </ul> <p>BTW, <em>Ubuntu</em> (obviously common pre-installed typeface) is a good UI font. The problem is that it looks “original”, so it shouldn't serve as a default sans-serif that will be used in a browser.</p> <h2 id="configuration-file">Configuration File</h2> <p>Here's an exemplary <em>font.conf</em> file content. It uses <a href="https://www.freedesktop.org/wiki/Software/fontconfig/">Fontconfig</a>, a library for system-wide font configuration.</p> <pre><code>&lt;?xml version=&quot;1.0&quot;?&gt; &lt;!DOCTYPE fontconfig SYSTEM &quot;urn:fontconfig:fonts.dtd&quot;&gt; &lt;!-- $XDG_CONFIG_HOME/fontconfig/fonts.conf <span class="color-bright">for </span>per-user font configuration --&gt; &lt;fontconfig&gt; &lt;!-- basic aliases --&gt; &lt;alias&gt; &lt;family&gt;sans-serif&lt;/family&gt; &lt;prefer&gt;&lt;family&gt;Roboto&lt;/family&gt;&lt;/prefer&gt; &lt;/alias&gt; &lt;alias&gt; &lt;family&gt;serif&lt;/family&gt; &lt;prefer&gt;&lt;family&gt;IBM Plex Serif&lt;/family&gt;&lt;/prefer&gt; &lt;/alias&gt; &lt;alias&gt; &lt;family&gt;monospace&lt;/family&gt; &lt;prefer&gt;&lt;family&gt;IBM Plex Mono&lt;/family&gt;&lt;/prefer&gt; &lt;/alias&gt; &lt;!-- If you don't want something, use something else instead --&gt; &lt;match target=&quot;pattern&quot;&gt; &lt;test qual=&quot;any&quot; name=&quot;family&quot;&gt; &lt;string&gt;Arial&lt;/string&gt; &lt;/test&gt; &lt;edit name=&quot;family&quot; mode=&quot;assign&quot; binding=&quot;same&quot;&gt; &lt;string&gt;Roboto&lt;/string&gt; &lt;/edit&gt; &lt;/match&gt; &lt;match target=&quot;pattern&quot;&gt; &lt;test qual=&quot;any&quot; name=&quot;family&quot;&gt; &lt;string&gt;Georgia&lt;/string&gt; &lt;/test&gt; &lt;edit name=&quot;family&quot; mode=&quot;assign&quot; binding=&quot;same&quot;&gt; &lt;string&gt;IBM Plex Serif&lt;/string&gt; &lt;/edit&gt; &lt;/match&gt; &lt;match target=&quot;pattern&quot;&gt; &lt;test qual=&quot;any&quot; name=&quot;family&quot;&gt; &lt;string&gt;Times New Roman&lt;/string&gt; &lt;/test&gt; &lt;edit name=&quot;family&quot; mode=&quot;assign&quot; binding=&quot;same&quot;&gt; &lt;string&gt;IBM Plex Serif&lt;/string&gt; &lt;/edit&gt; &lt;/match&gt; &lt;/fontconfig&gt; </code></pre> <p>A file like this should be placed at <code>$XDG_CONFIG_HOME/fontconfig/</code>.</p> <h2 id="docs">Docs</h2> <p>Need more info?</p> <ul> <li><a href="https://www.freedesktop.org/software/fontconfig/fontconfig-user.html">Official documentation</a>.</li> <li><a href="https://wiki.archlinux.org/title/font_configuration">ArchLinux docs</a> have good tips too.</li> </ul> <h2 id="potential-problem">Potential Problem</h2> <p>This piece of code will cause replacement of <em>Times New Roman</em> for <em>Merriweather</em>:</p> <pre><code>&lt;match target=&quot;pattern&quot;&gt; &lt;test qual=&quot;any&quot; name=&quot;family&quot;&gt; &lt;string&gt;Times New Roman&lt;/string&gt; &lt;/test&gt; &lt;edit name=&quot;family&quot; mode=&quot;assign&quot; binding=&quot;same&quot;&gt; &lt;string&gt;Merriweather&lt;/string&gt; &lt;/edit&gt; &lt;/match&gt; </code></pre> <p>This one, not necessarily:</p> <pre><code>&lt;alias&gt; &lt;family&gt;Times New Roman&lt;/family&gt; &lt;prefer&gt; &lt;family&gt;Merriweather&lt;/family&gt; &lt;/prefer&gt; &lt;/alias&gt; </code></pre> <p>It will work only if there's no <em>Times New Roman</em> in your system.</p> <h2 id="quick-sum-up">Quick sum-up</h2> <ul> <li>Store your fonts at <code>$HOME/.local/share/fonts</code> or <code>/usr/local/share/fonts</code></li> <li>Configuration stuff write into <code>$XDG_CONFIG_HOME/fontconfig/fonts.conf</code> file. (<code>$XDG_CONFIG_HOME</code> most likely means <code>$HOME/.config/</code>.)</li> <li>Use fonts that look clean and standard — you need <strong>predictable behavior</strong>.</li> </ul> <p><code>2021-12-18</code></p>
