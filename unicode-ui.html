Unicode Symbols for UI – a Handy Glossary

Unicode is a text encoding standard with an abundant collection of symbols and characters. It works practically everywhere – text files, terminal, web pages, and so on. Beside obvious stuff like alphabets, you get advanced math symbols, emojis, arrows, box-drawing shapes, etc.

Since it's a text encoding system, you can treat it just like any text. Basically, you can change it's color, size and placement, also interactively. You will get really light and simple, verbose if needed, GUI.
